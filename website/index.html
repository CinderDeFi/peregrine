This is a bootstrap scaffold, not production software. It has never been audited or deployed, and holds no value. The honest limitations section of the README is long on purpose, and SECURITY.md lists what is deliberately unsafe.

Verify, don't trust

Most chains ask you to trust an RPC provider for reads. Peregrine's answer is that every read carries its own proof, and every cross-chain fact is re-derived from cryptography the verifier checks itself — no multisig, no privileged key, no trusted relayer anywhere.

Slipstream

Signed records ride inside consensus vertices rather than queueing behind blocks, then materialize into a queryable table.

Stoop BFT

An uncertified DAG in the Mysticeti lineage. Finality is a function of round-trip time, not block time.

TalonVM

A metered stack machine with a dual meter — compute units and data bytes — so data-heavy work is priced honestly.

Proven interop

Ethereum state verified inside a zkVM at consensus time, and a reciprocal Solidity client so Ethereum can read Peregrine.

Try it in ten seconds

A real 4-validator network over real QUIC, end to end.

git clone https://github.com/peregrine-labs/peregrine && cd peregrine
cargo install --path crates/peregrine-cli

peregrine demo          # the whole tour: streams, VM, light client, interop
peregrine devnet up     # a local network with a client RPC endpoint
peregrine watch         # live dashboard — every value re-verified locally

The demo's fourth act is the one to watch: a contract tries to read Ethereum state that has not been proven, and the transaction traps. Missing data is an error, never a zero.

Verify a read, in the browser

The TypeScript SDK reimplements proof checking independently of the node. It understands both Merkle tree versions and refuses a version it does not know rather than guessing — verifying under the wrong rule would silently disagree with the chain. 

import { verifyProvenRead, provenReadFromJson } from "@peregrine/sdk";

const read = provenReadFromJson(await res.json());
if (!verifyProvenRead(read, trustedStoreRoot)) {
  throw new Error("the node lied");
}
